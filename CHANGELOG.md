# Changelog

All notable changes to this project will be documented in this file.

## [2.4.0] - 2026-04-07

### Added

- `useThrottle`: Throttle rapidly changing values
- `useResizeObserver`: Observe element size changes with ResizeObserver
- `useNetworkStatus`: Track online/offline browser status

## [2.3.0] - 2026-04-07

### Changed

- Updated npm package metadata for better credibility and discoverability
- Moved `react` and `react-dom` from dependencies to peer dependencies
- Added `homepage`, `bugs`, `funding`, and `publishConfig` fields
- Improved package description and expanded SEO-focused keywords
- Synced documentation metadata with current package state

## [2.1.1] - 2024-11-23

### Added

- Initial release of `react-lite-hooks`
- `usePersistentState`: State that survives page reloads
- `useClipboard`: Copy text to clipboard
- `useMediaQuery`: Track CSS media queries
- `useOnScreen`: Detect element visibility
- `useToggle`: Simple boolean state manager
- `useDebounce`: Delay value updates
- `useOnClickOutside`: Detect clicks outside element
- `useWindowSize`: Track window dimensions
- `usePrevious`: Access previous state value
- `useEventListener`: Manage event listeners safely
- `useHover`: Track element hover state
- `useInterval`: Declarative setInterval
- `useKeyPress`: Detect specific key presses
- `useIsFirstRender`: Check if it's the first render
- `useTimeout`: Declarative setTimeout
